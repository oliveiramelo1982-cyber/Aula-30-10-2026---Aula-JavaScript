INOVA9 — ESTRUTURA DOS DADOS
================================

Conjunto de dados: registros de produção.
Armazenamento: localStorage do navegador.
Chave utilizada: inova9_registros_producao
Formato de gravação: JSON (array de objetos).

CAMPOS DE CADA REGISTRO
-----------------------
id                    Number   Identificador único do registro.
dataRegistro          String   Data da produção no formato AAAA-MM-DD.
maquina                String   Nome ou identificação da máquina utilizada.
responsavel            String   Nome do funcionário responsável pelo lançamento.
producaoPlanejada      Number   Quantidade de peças planejadas (inteiro maior que zero).
pecasProduzidas        Number   Quantidade de peças produzidas (inteiro não negativo).
pecasPerdidas          Number   Quantidade de peças perdidas (inteiro não negativo).
aguaLitros             Number   Consumo de água em litros (valor não negativo).
energiaKwh             Number   Consumo de energia em kWh (valor não negativo).
materialRecicladoKg    Number   Quantidade de material reciclado em kg (valor não negativo).

REGRAS DE VALIDAÇÃO
-------------------
- Data, máquina e responsável são obrigatórios.
- A produção planejada deve ser maior que zero.
- As quantidades de peças devem ser inteiras e não negativas.
- As peças perdidas não podem ultrapassar as peças produzidas.
- Água, energia e material reciclado devem ser valores não negativos.

OBSERVAÇÃO
----------
Os dados são persistidos localmente no navegador. Permanecem após atualizar
ou reabrir a página no mesmo navegador, mas não são sincronizados com outros
computadores ou navegadores.
